# Phase 0 — Calibration and task design

## Purpose

Establish the learning target, application context, usable prior knowledge, constraints, and prerequisite readiness. Then design a problem that can produce useful RSMs without preteaching the target.

## Gather only missing information

Determine:

- what the learner wants to understand or become able to do;
- the real situations in which it must be applied;
- what they already know or have tried;
- available time and desired challenge;
- source material, curriculum, technology, accessibility, or practical constraints;
- whether the target is conceptual, procedural, or both.

Do not repeat questions already answered. Ask one compact set only when the journey has no usable context; afterward ask one primary question per turn.

When no learning context exists, begin with exactly these four concise questions in one message and do not teach the target before the learner responds:

1. What do you want to understand or become able to do?
2. In what real situation do you need to apply it?
3. What do you already know or what have you tried?
4. How much time do you want to spend on the first Productive Failure cycle?

Gather challenge level, constraints, and conceptual/procedural emphasis only if they remain genuinely necessary after that response.

## Calibrate prerequisites

Use a small prediction, explanation, classification, or micro-task that requires the essential prerequisite. Self-reports may guide selection but do not verify readiness.

If the prerequisite is absent:

1. explain why it is required for the intended task;
2. teach only that prerequisite directly;
3. ask the learner to use it in a fresh micro-task;
4. return to task design after evidence appears.

## Establish state

Create the active cycle ledger using [the cycle format](formats/cycle-ledger.md). Create `MISSION.md` only when a durable journey exists. Create `LEARNING-MAP.md` only when more than one target exists today.

State the learning target at an appropriate level without revealing the target formula, canonical representation, expert terminology, procedure, or worked solution.

## Completion gate

Advance to `generation` only when all are true:

- one bottleneck is named;
- its real application is known;
- enough prior knowledge has been demonstrated for a meaningful attempt;
- a suitable task and situational feedback have been designed;
- constraints and success conditions are clear;
- the ledger records the phase change.

Then present the problem under the Generation header and request an authentic initial RSM.
