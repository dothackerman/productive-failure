# Completed learning record format

```markdown
---
cycle: 1
target: ""
completed: YYYY-MM-DD
path: pf | direct-instruction
evidence_level: near-transfer | far-transfer
---

# Learning record — <target>

## Prior knowledge activated

## RSMs generated

## Critical features noticed

## Critical features initially missed

## Canonical account assembled

## Evidence
- Procedural application:
- Conceptual explanation:
- Near transfer:
- Discrimination:
- Far transfer:

## Remaining uncertainty

## Fresh retrieval task for a later session

## Recommended next target
```

Create this record only after the cycle completion gate. Use `near-transfer` when an independent near-transfer attempt supports the record and `far-transfer` only when an actual far-transfer attempt also supports it. Keep incomplete evidence in the active cycle ledger.
